本次从 0.6.2 升级到 0.6.3，在管理页账号详情的额度窗口容量估算行补充折算 API 价格展示。

**账号额度视图**

- 5 小时 / 周额度窗口的容量估算行追加按本周期均价（`$/credit`）折算的 API 标价：常规估算显示 `· ≈ $X.XX`，仅有下限时显示 `· ≥ $X.XX`。
- 折算仅统计本周期内同时包含 API 价格与 credits 的已计入请求；无配对数据时不追加显示。
- 底部「本周期 API 价格」行保持仅展示当前已用金额，不重复预测。

**升级说明**

本次在读取时实时计算折算价格，不涉及数据库 schema 变更（维持 schema v22）或配置项变化，可从 0.6.2 直接平滑升级。

安装与备份方法见[部署指南](https://github.com/Seia-Yurizono/ciallopa/blob/v0.6.3/docs/DEPLOYMENT.md#image-tags-and-upgrades)。
