本版本整合转发、usage 存储与服务生命周期重构，并更新 Codex 0.169.0 的 WebSocket 兼容处理。

**转发与服务**

- 拆分 HTTP / SSE / WebSocket 转发模块，明确请求、连接和 usage 记录的结束时机；共享 SSE 分帧与响应处理，减少中间分配。
- 整合路由健康状态、重试策略、账号快照与管理接口状态；UI 共享样式和页面切换逻辑。
- 保留 Codex 0.169.0 的 WebSocket 帧限制、发送及超限关闭处理。
- 压测确认 WebSocket 与 usage 查询的性能改善；收益随负载变化。短 SSE 请求在此前云端测试中仍有额外 CPU 开销，本版本不承诺所有 SSE 场景均恢复到旧 main 水平。

**usage 数据库**

- 增加快照读取连接池、批量查询和独立 threads 字典，减少重复字典与查询开销。
- schema 自动升级至 v17：v16 分离 threads 字典并清理旧标签；v17 将 requests_account 改为单列 account 索引，利用 SQLite 已包含的 rowid 保持按账号、请求 ID 查询能力，避免显式重复存储 ID。
- 优化 v16 迁移的临时数据处理，降低迁移内存；增加迁移限额验证与精确 SSE 复现工具。
- 首次启动会迁移旧库，耗时取决于数据规模。升级前请停止服务并备份数据库及相关 WAL 文件；如需退回旧版，请恢复升级前的备份，旧版不能直接使用已迁移的 threads 字典结构。

**升级与验证**

- 应用版本为 0.5.0，数据库版本独立为 v17。安装与镜像标签策略见[部署指南](DEPLOYMENT.md#image-tags-and-upgrades)。
- 发布前本地完整 Rust 测试 553 项通过，严格 Clippy、格式和 Node 状态检查通过；最终分支亦通过云端测试。
- 合成百万行 v15 / v16 数据库在 128 / 256 MiB、禁用 swap 的限额下升级至 v17 均通过，数据与完整性检查通过，无 OOM。这不代表任意真实数据库都具有相同峰值。
- 安装包、容器及发布提交的完整检查由标签工作流执行。
