本版本修复自动使用重置卡的恢复行为，并改进请求详情与概览指标展示。

**重置卡恢复**

- 按持久化账号别名读取恢复历史，修复重试次数和终止状态无法正确匹配的问题；恢复历史不再受页面展示条数限制。
- 重试间隔从数据库恢复，重启或关闭再开启自动使用不会重置 60 秒间隔与五次尝试上限。
- 消费前保存卡片到期时间；已知过期的自动 pending 在账号消费锁内记为 expired，不再阻塞后续卡片。仍有效、到期时间未知或手动发起的 pending 保持保护；expired 不表示已确认上游消费结果。
- 收到 already_redeemed 后查询额度，只有明确确认额度恢复才清除额度冷却。冷启动时卡片发现失败会在 60 秒后重试。

**管理页面与文档**

- 概览指标按请求结果、响应性能、用量费用分组。
- 请求详情仅在有尝试记录时显示“查看尝试”；改善空响应展示和切换记录后的键盘焦点。
- 整理 UI 实验资料与 Claude 兼容方案，并标明历史证据及尚未实现、未实测的内容。

**升级与验证**

- usage 数据库自动升级至 schema v18，新增可空的 credit_expires_ms 列；旧记录不会被填入推测的到期时间。迁移保留已有数据及预先存在的到期值，支持重复打开。
- 升级前请停止服务并备份 usage 数据库及相关 WAL 文件。安装与镜像标签说明见[部署指南](https://github.com/Seia-Yurizono/ciallopa/blob/main/docs/DEPLOYMENT.md#image-tags-and-upgrades)。
