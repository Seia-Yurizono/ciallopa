本次从 0.5.4 升级到 0.6.0，重点是重做管理界面：把日常监控、请求排查、账号维护和配置操作整理为一致的五个视图。保留 0.5.4 的额度周期修复，本次没有新增数据库迁移。

**五个视图，连贯排查**

- 概览：集中查看请求、失败率、延迟、Token、参考费用和容量；用趋势图、分布条和额度条呈现运维信息，点击或框选时间段继续查看请求。
- 请求：按问题和原因筛选，查看请求分布、列表与详情；概览与请求共享时间、账号、模型、API Key 和实例范围，链接保留排查条件。
- 账号：统一呈现状态、额度、周期历史和调度设置，并提供添加账号、刷新额度与重置卡等已有能力的操作入口。额度估算区间与确定数值区分显示。
- 设置：按用途分区，支持搜索、修改草稿和保存前差异检查，明确哪些修改需要重启；配置冲突时保留草稿供重新检查。
- 系统：用图表和占用条查看内存、缓冲、WebSocket、并发及近期趋势，突出用量写入缺口和资源告警。

**桌面和手机导航**

- PC 使用可折叠侧栏，手机使用底部标签栏和“更多”面板；请求列表在手机上改用卡片，长详情以全屏页面显示。
- 统一浅色、深色与跟随系统主题，提供中英文切换、键盘快捷键、弹层焦点管理和触屏图表操作。
- 保留旧请求筛选链接与系统页入口的跳转兼容，详情关闭后回到列表原位置。

**刷新与交互改进**

- 刷新尽量保留滚动位置、焦点和展开状态；浏览历史请求时，以浮动的新请求提示代替打乱当前列表。
- 设置草稿不会被后台刷新或语言切换覆盖；切换身份后，旧请求的迟到响应不会影响新登录。
- 修复滚动时间窗更新时图表选中位置偏移，以及修改出口代理后顶栏状态未及时更新等问题。
- 管理页面继续内嵌在单个二进制中，无需前端运行时；支持 gzip 传输，减少页面下载量。

升级前的备份与安装方式见[部署指南](https://github.com/Seia-Yurizono/ciallopa/blob/v0.6.0/docs/DEPLOYMENT.md#image-tags-and-upgrades)，各视图的操作和指标口径见[界面说明](https://github.com/Seia-Yurizono/ciallopa/blob/v0.6.0/docs/UI.md)。参考费用仍是估算，不是账单；本次不宣称新增真实模型上游兼容性。
