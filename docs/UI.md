# 管理界面

管理界面围绕“发现异常 → 缩小范围 → 查看请求 → 回到原处”组织。它是一个单文档应用，用 History API
切换五个视图：概览 `/ui`、请求 `/ui/requests`、账号 `/ui/accounts`、设置 `/ui/settings`、系统 `/ui/system`。
页面由 Rust 静态嵌入交付（支持 gzip），部署不需要前端运行时。源码结构、视图契约、组件、CSP 与开发方式见
[crates/server/src/ui/README.md](../crates/server/src/ui/README.md)，指标口径见 [METRICS.md](METRICS.md)。

## 应用壳与导航

- 登录：输入访问密钥（即调用 ciallopa 的 API Key）。密钥只保存在当前标签页的 sessionStorage，关闭标签页后清除；
  「退出」清除密钥和只属于当前身份的显示。旧登录迟到的 401/403 不会清掉新登录。概览、请求只需普通密钥；
  账号、设置、系统的进程状态需要 `admin = true` 的密钥，否则显示“此页面需要管理密钥”，并可换密钥登录。
- 桌面左侧是导航栏（运维：概览、请求、账号；配置：设置、API Key；系统），可以收起成图标栏（Ctrl/⌘ + B 或 `[`，
  保存在本浏览器）；768–1023px 默认是图标栏。手机底部是标签栏：概览、请求、账号、更多（设置、系统、主题、语言、退出）。
- 账号导航上的红色数字是需要重新登录的账号数；系统导航上的数字是需要注意的系统项（出口被拦截、内存或用量记录告警）。
- 顶栏右侧：出口标签（直连 / 出口代理，近 1 小时出口代理错误数，点击打开网络设置）、立即刷新（显示上次刷新时间）、
  自动刷新开关、主题（跟随系统 / 浅色 / 深色）和语言。
- 全局横幅显示在顶栏下、每个视图上方：
  - 没有可用账号（全部停用或需要重新登录，或还没有账号）时显示“没有可用账号”，带账号页入口；
  - 上游 Cloudflare 拦截或质询本机出口（如 1010）时显示错误码、最近时间、次数（悬停看首次时间、账号、上游状态和
    cf-ray），提示这类请求不换账号、不冷却账号，直到下一次正常的上游响应；带出口设置入口。
- 旧地址仍然可用：`/ui#system` 跳到 `/ui/system`；带请求筛选参数（`fproblem`、`record` 等）的 `/ui?…` 跳到 `/ui/requests?…`；
  账号深链 `/ui/accounts#acc=<id>`（可加 `&act=quota|cooldown|cards|sched`）；设置分区用 `#routing`、`#network`、
  `#prices`、`#keys`、`#audit` 等。
- 快捷键（`?` 显示列表）：`g` 后按 `o/r/a/s/y` 切换视图，`/` 聚焦搜索或筛选，`J/K` 上下移动，`Enter` 打开详情，
  `Esc` 关闭弹层。

## 共享范围

时间、账号、模型、API Key 和实例是共享范围，显示在概览和请求的范围栏，两个视图共用，切换视图时保留。

- 时间：最近 1 小时 / 24 小时（默认）/ 7 天 / 30 天，最近一次选择保存在本浏览器；「固定」把当前滚动窗口固定成
  绝对起止时间（最长 31 天），便于分享链接。分享时固定时间边界，但不承诺重新打开时记录仍在保留期内。
- 账号、模型、API Key、实例：从候选中选，或用“包含…”做不区分大小写的包含匹配。每个条件是可单独移除的标签，
  「清除全部」只清共享范围。窄屏和 1280px 以下把全部字段收进一个“筛选”面板。
- URL 沿用旧参数名（`range`、`from`/`to`、`facct`、`fmodel`、`fkey`、`finstance`），默认值不写进 URL。
- 含预热：默认不含 Codex WebSocket 预热（`generate:false`）。打开后 Token、费用、趋势、分组和请求列表计入预热；
  请求数、失败率和延迟始终不含预热。概览和请求共用这个开关，保存在本浏览器。

## 概览

概览回答“这段时间好不好、钱和额度怎么样、哪里有问题”。所有数字随共享范围变化，除非注明“不受时间范围影响”。

- 指标：请求（含 RPM，窗口平均）、失败率（含上游失败率）、TTFT（p50 与 p90，样本数）、生成速度、Token（入 / 出、
  缓存命中比例、未报告用量的条数）、参考费用（按 API 标价估算，不是账单；未定价条数与“设置价格”入口）。
  每项的口径写在 ⓘ 说明里；“对比上一周期”打开后显示与等长上一周期的差值。未知值显示 —，与 0 区分。
- 趋势：可切换指标（请求、Token、费用、失败、延迟、占用）和粒度（自动 / 按小时 / 按天），可叠加上一周期。
  点击一段查看这段时间的请求，拖选缩小时间范围；触屏上再点一次进入请求。
- 问题：失败（计入失败率，按额度用尽、限流、请求内容、上游错误、网络、流中断、本地、其他分类）与未完成
  （客户端断开、上游截断、未确认结束，不计入失败率），每类可点进请求；下方是最近报错。
- 容量：
  - 额度剩余：5h 与周窗口各一条分段条，每段一个启用且有该窗口的账号，填充为剩余比例（上游最近一次快照，不受时间
    范围影响）；需要重新登录或额度未知的账号单独标出。点按查看每个账号。
  - 实时：当前并发与 WS 连接及其上限（不受时间范围影响，需要管理密钥；进程关闭中会注明）。
  - 区间峰值：所选时间段的并发 / WS 峰值和满载分钟数，点击切到占用趋势。
  - 已拒绝：达到本地上限返回 503 的次数，按原因分列，不计入失败率；只随时间、API Key 和实例变化，按账号或模型
    筛选时不统计。
- 分布：按账号、API Key、实例、模型分组（「更多」里还有实际模型、接口、推理强度、传输、档位、错误码、错误来源），
  列出请求、失败、上游、TTFT p50、耗时 p50、重试、降级、Token 和费用。点一行把该值加入共享范围（对应共享字段时）
  或带条件进入请求。分组选择、趋势指标保存在本浏览器。
- 读取失败时保留最近一次结果并标“更新失败”，可重试；空范围显示“这段时间没有请求”。

## 请求

请求是调查视图：顶部问题分组，中间请求分布图，下面是请求列表（手机为卡片）。

- 问题分组：全部 / 报错 / 上游出错 / 未完成 / 本地拒绝，各带数量。选中后第二行是原因：
  - 报错：额度、限流、请求内容、上游、网络 / 出口代理、ciallopa、流中断；
  - 上游出错：未救回、已救回（上游中途出错但客户端最终收到正常结果）；
  - 未完成：客户端断开、需重连、上游截断、内容过滤、未确认结束；
  - 本地拒绝：并发上限、WS 上限、请求体缓冲、WS 消息缓冲（按分钟分组，显示次数与当时占用）。
  分组下的说明只陈述口径（“报错计入失败率”“未完成不计入失败率”“已救回 N · 未救回 M”），不新增比率。
  分组、原因、是否救回和下一步都由后端判定，界面只显示后端给出的 `problem`、`cause`、`rescued` 与 `next`。
  拒绝发生在选择账号之前，按账号、模型或请求条件筛选时本地拒绝不可选。
- 更多筛选：结果、失败原因、错误来源、档位、错误码、会话、只看重试或换过账号的、含预热，以及旧链接用的旧错误条件。
  这些条件只缩小请求列表，不改变概览的分母，也不影响请求分布图。生效条件显示为可单独移除的标签。
- 搜索：16 位记录 ID 直接打开该请求的详情；会话 ID（完整或连续至少 8 位，不区分大小写）筛选该会话。会话不受时间
  范围限制，查整个保留期（数量后注明“不限时间”），分布图里选中的时间段仍然生效；片段对应多个会话时提示粘贴更长的
  ID。本地拒绝没有会话信息，选择会话会离开本地拒绝视图。
- 请求分布：按共享范围统计的全部请求，失败部分标红，本地拒绝单独一色。点击一段或拖选几段只看这段时间
  （URL 参数 `rfrom`/`rto`），可以“返回整个范围”。
- 列表：时间、状态、模型（实际模型不同、Fast / 降级、推理强度有标记）、耗时条（浅色段是 TTFT）、账号、Token、尝试、
  API Key、参考费用和下一步。按记录 ID 游标追加（“加载更多”），行按 ID 复用，未变的行不重建。固定时间窗不等于数据库
  快照：迟到完成的请求仍可能出现在已加载的时间窗内。
- 停在列表顶部时新请求直接插入；向下浏览或打开详情时，新请求不打乱列表，而是在顶栏下方浮出“N 条新请求”，
  点击回到最新；已加载多页时自动刷新不再改动列表。
- 下一步：每行最多两个（窄屏只显示第一个）。下一步只跳转或打开已有视图，从不使用重置卡：刷新额度（账号页该账号的
  额度刷新按钮）、查看账号 / 账号状态 / 查看冷却（账号页）、检查出口（网络设置）、排查详情（请求详情，有尝试记录时
  定位到尝试过程）。
- 未知用量与明确的 0 分开显示；未定价、已忽略的模型费用分别标出。

## 请求详情

- 位置：1280px 及以上在列表右侧并排；更窄是右侧抽屉；手机是全屏页面。提供上一条 / 下一条、复制 JSON、复制链接
  （固定时间范围）和关闭，关闭后回到列表原位置和原焦点。
- 顶部结论块说明发生了什么、是否计入失败率（已救回的请求也计入上游出错），并重复下一步按钮；被重试或换账号救回的
  请求写明“重试 N 次后成功”或“换账号 A → B 后成功”；加密推理内容来自其他账号时提示需要在客户端新开会话。
- 数字：TTFT、总耗时、Token 输入 → 输出（缓存、推理）、生成速度和参考费用，时间轴区分等待首个 Token 与生成。
- 尝试过程：每次尝试的账号、结果和处理（成功、换账号、重试、冷却后继续、停止并返回客户端），时间相对请求开始。
- 网关下游观测：上游事件、SSE 入队 / 交给 HTTP 层、WS 发送完成与下游阻塞累计，在网关侧测量，不代表客户端收到的时间；
  旧记录没有时注明。
- 标识与元数据：记录 ID、账号（及最初账号）、API Key、实例、接口、传输、模型 / 实际模型、推理强度、档位、会话、轮次、
  结束原因和上游请求 ID。会话显示尾 8 位（UUIDv7 开头是时间，相邻会话开头相同），可复制完整 ID；“只看这个会话”清除
  请求条件、选中时间段和共享范围的账号、模型、API Key、实例（中途换账号的会话也能看全）。
- 错误详情：响应头与已脱敏的响应体（注明原始字节数、是否截断），空内容显示“（无）”。读取失败可原位重试，这里的
  重试只重新读取详情，不重新发送模型请求；已过保留期时继续显示概要。
- 详情读取绑定当前记录、面板代次和登录身份；关闭、切换记录或退出后，迟到的响应不会覆盖新内容。

## 账号

- 顶部摘要：可用账号数（未停用且令牌有效，冷却中的也算）、按状态划分的比例条、账号选择策略、配置可编辑 / 只读、
  更新时间。额度读取失败时保留最近成功快照并注明时间；冷却、只读等说明以页内横幅显示。
- 工具栏：重新扫描目录、刷新全部额度（只读，不消耗额度；同一账号 30 秒内只查一次）、导入文件、添加账号（唯一的
  实心主按钮）。手机上重新扫描和导入收在“更多”菜单。设备码登录进行中时显示“设备码登录等待中”，点击回到登录步骤。
- 每行一个账号：状态（正常、冷却中、已停用、需要重新登录）、5h 剩余与周剩余（按上游返回的 `window_minutes` 判断窗口，
  不按套餐猜；只有周窗口的账号如 Pro 不显示 5h 占位）、重置时间、点数余额（「点数 812.5」「点数 不限」「无点数」，
  上游没报过就不显示）、30 天容量小图（周窗口一条线和重置点）、近 24 小时请求、Token 与报错数、重置卡张数。数据较旧时
  每行只标一次“旧数据”，悬停看上次读取时间。「额度」指订阅包含的额度（单位 credits），「点数」指另外购买的点数。
- 详情：桌面是右侧抽屉，手机是全屏页面。分为
  - 状态：冷却到期时间与解除冷却、最近一次额度刷新结果、近 24 小时 overloaded 次数；
  - 额度周期 · 30 天：同时有 5h 和周窗口时可切换（默认周，本次会话记住），每个周期一行，新的在上，所有行共用一条
    credits 刻度。蓝色块是估算容量（斜纹是估算范围，只有下限时末端渐隐），其中深色细条是已用额度；额度用满后另扣
    的点数单独标「点数 N · $x.xx」，不计入已用、容量和 API 价格。还没估出容量的进行中周期画成虚线框并写“估算中”，
    不写 0。纵轴从 0 开始，偏离很远的周期贴在上沿画 ▲，实际数值见右侧数字和明细。点一行展开明细（容量、范围、已用、
    API 价格、点数、起止时间、快照数、可信度、结束方式）。5h 默认显示最近 12 个周期。
    「重置估算…」只改用量日志（配置只读时也能用），可选当前窗口或全部窗口；旧周期归档变灰不删除，30 天内可以撤销；
  - 调度：权重（加权轮询时使用，0 = 不参与）、优先级（大的优先），保存后立即生效并可撤销，必须是整数；参与账号选择、
    重置卡快到期时自动使用、自动刷新额度三个开关，改动立即生效，失败时回滚；
  - 重置卡：可用张数、到期时间、使用（指定一张或由上游选择，必须二次确认；上游返回处理中时重试沿用同一张卡和同一请求
    ID）、刷新卡列表、显示已使用；
  - 维护：刷新额度、刷新令牌（需确认）、删除账号（需确认，可改为停用；最后一个可用账号额外提醒）。
- 添加账号：弹窗里选设备码登录（推荐）、粘贴 auth.json 或导入文件。设备码登录显示链接、一次性代码和倒计时，完成后
  自动添加；“停止等待”只停止页面轮询，不撤销服务端已开始的授权。导入一次最多 100 个文件，服务端检查后写入账号目录，
  结果按已添加、已存在、已跳过（含原因）汇总。直接放进账号目录的文件会自动加载。
- 配置只读（未设置 `[ui] allow_config_write = true`）时不能添加、导入、编辑或删除；刷新额度和重置估算仍可用。
  密钥不能使用重置卡时，重置卡区显示只读说明。

## 设置

- 分区：转发（账号调度、网络、限流与容错、图片接口）、数据与账号（用量、模型价格、账号与重置卡）、系统（常规、
  API Key、变更记录）。桌面左侧是分区目录，手机先显示目录再进入分区。搜索覆盖全部设置的名称、说明和键名；
  “只看已修改”列出与默认值不同或未保存的项。
- 每项显示说明与默认值；有固定取值的选项（如选号策略）以单选列表逐项说明；“0 = 关闭”的数值项单独有开关。
- 草稿：修改先进入草稿，底部栏显示未保存数量，「检查并保存」列出每项的旧值、新值和生效方式（立即生效或需要重启；
  手机上需要重启的项在键名旁标注）。保存带版本校验：配置已被别处修改时保留草稿，重新检查可查看最新配置与草稿的差异；
  保存成功但重新读取失败时单独提示，草稿保留。
- 放弃草稿需在确认框中明确选择，默认聚焦取消；离开页面、切换语言、后台刷新都不会丢草稿。有未保存修改时，立即生效
  的出口代理开关不能单独切换。服务端校验错误标在对应字段上，改动后清除。
- 网络分区可测试出口代理连通性。模型价格只在点「检查更新」时联网：比较新增和变化的模型后再应用，可为单个模型设置
  价格或忽略（费用按 0 计）。
- API Key：只显示标签和末 4 位；新建的 Key 只显示一次，关闭后不能再查看；可删除。变更记录显示最近 20 条，包括账号页
  和配置文件的改动。
- 配置只读时显示说明，不提供输入框和新建 Key。

## 系统

系统视图显示本进程当前状态，不受共享范围影响，内存、缓冲和并发需要管理密钥（无权限时用量记录计数仍可查看）。

- 内存：进程 RSS（含启动以来峰值）、jemalloc 已分配与驻留；系统不提供或未使用 jemalloc 时注明。
- 请求体缓冲：当前占用 / `max_buffered_body_mb`；空间不足时最多等待 1 秒，仍不足则 HTTP 返回 503、WebSocket 消息收到
  可重试的 503 错误帧。
- WebSocket 连接：连接数 / `ws_max_connections`（0 显示“不限”）及其缓冲占用。
- 并发：在途请求 / `max_inflight_requests` 和启动以来的拒绝次数；进程正在关闭时显示说明。
- 近期趋势：每隔几秒采样一次，只保存在内存（最近 15 分钟，重启后清空），可看内存、缓冲、WS。
- 告警：缓冲占用接近上限、WS 连接达到上限时页内显示“需要注意”，并计入系统导航上的数字。
- 用量记录：启动以来的已接收、已写入、丢弃、写入失败、已清理计数；有丢弃或写入失败时提示“用量记录有缺口”，
  因为用量是尽力写入，缺口里的请求不会出现在统计中。

## 刷新与编辑

- 自动刷新默认关闭；打开后间隔可选 5 / 15 / 30 / 60 秒（默认 15），保存在本浏览器；标签页不可见或有对话框打开时暂停。
  「立即刷新」随时可用。
- 刷新保留滚动位置、展开状态和焦点：列表按 ID 复用行，局部重绘时以可见元素为锚点补偿高度变化。
- 读取失败保留最近一次成功结果并标明时间；失去权限或不可用时不再把旧数据当作当前数据。
- 设置草稿和进行中的添加账号流程不会被后台刷新覆盖。
- 会改变状态的操作给出结果提示；可撤销的操作（停用、权重和优先级、重置估算等）在提示里带「撤销」。

## 双语

- 中文与英文全量对照（检查脚本校验两边词条一致）。默认按浏览器语言（zh* 为中文，其余为英文），语言按钮切换后
  保存在本浏览器；切换不重新加载页面，草稿和展开状态保留。
- 专业术语保留英文原样（Token、API Key、TTFT、WS），中文与英文、数字之间留空格，标点用全角。英文里
  “Purchased”对应点数、“Quota”对应额度。
- 时间按浏览器本地时区显示。

## 按钮与可点元素约定

- 同一屏只有一个实心主按钮（如账号页的「添加账号」、设置的「检查并保存」）；其余带文字的操作是细边框按钮。
- 开关和展开类按钮按下时显示浅底和深一点的边框（`aria-pressed` / `aria-expanded`）。没有边框的只有纯图标按钮，
  并带说明文字。
- 删除用红色描边，确认框里才用实心红。跳转用文字链接加 › 或 ↗。
- 能点的小号数字（已拒绝、客户端断开、网络等）平时有淡色点状下划线，悬停或聚焦变实线；大号数值不加。
  不可点的计数只有圆点和文字，不画胶囊边框。
- 键盘能到达所有操作，弹层关闭后焦点回到打开它的元素；操作不依赖鼠标悬停，悬停提示里的信息在详情里也能看到。
- 触屏下可点元素至少 44px，外观紧凑的按钮用透明扩展区补足；手机左右和底部使用 `env(safe-area-inset-*)`。
- 图表按实际像素宽度绘制，不拉伸；样式通过 CSSOM 或 SVG 属性设置，不写内联 style（CSP 禁止）。

## 实现与设计依据

当前使用原生 HTML/CSS/JavaScript，按命名空间拆分（Core、I18n、Api、UI、Charts、Shell 与各视图），由 `ui.rs`
按清单拼成一个文档并嵌入二进制。以后以实际维护成本决定是否组件化，保留静态嵌入交付和 CSP 约束。

主要用于指标口径和钻取思路，不作为整页视觉模板。
