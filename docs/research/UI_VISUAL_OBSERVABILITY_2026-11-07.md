# UI 视觉评测：下游观测与“少读字”（2026-11-07）

分支 `feat/ui-visual-observability`，基于 `feat/downstream-observability`（c12ca51）。
方法沿用 [UI_HILL_CLIMBING.md](UI_HILL_CLIMBING.md)：固定任务 → 小步候选 → 截图复核 → 保留或回退。

## 来源与原则
- 用户要求：信息尽量由图形承载，减少阅读负担；不是删字、全图标、缩字号或全部 tooltip。
- 依据（研究笔记内已打开的原文）：NN/g Progressive Disclosure、NN/g Recognition vs Recall、
  IBM Carbon Status indicator / Dashboards、Grafana dashboard best practices。
  归纳：位置/长度/对齐/分组优先；状态用形状 + 颜色 + 短标签，不只靠颜色；同口径共轴、不堆叠；
  详情尽量不超过两层披露；图形有文本等价；unknown/null 与 0 区分。
- 方法参考：Theo 关于先做日常任务 eval、再在不回退下压缩复杂度的 X 帖子；Benji Taylor 视频的
  浅灰底白面板、字重层级、单一蓝色强调（不照搬展示型大留白/巨卡片）。

## 固定任务
T1 概况异常与范围；T2 每账号最紧额度窗口与重置时间，区分满/耗尽/未知/0；T3 区分正常/冷却/错误/需重登/停用；
T4 找最慢请求并判断上游慢或下游阻塞；T5 缺失值不显示为 0；T6 口径与单位可见（网关侧、非客户端收到；阻塞为累计无区间）；
T7 两侧压缩协商；T8 单 token / incomplete 不误导；T9 列表→详情→返回保留筛选/滚动/焦点；T10 375 宽、无 hover 依赖、暗色不退化。

## 轮次记录（截图由父级在浏览器完成并复核；此处只记可见结论）
- **Baseline**：账号页错误数在表格最右，远离状态；额度重置时间仅 hover；无数据仅“—”。
  请求列表需读耗时数字比较。详情观测为一列文字 + “更多”，上下游关系不可视。
- **R1**：账号额度格常驻重置时间、无数据虚线“未知”、状态形状、错误数移到状态旁；
  列表耗时共轴细条（TTFT 深色段）；详情上下游平行双轨，轴到所有里程碑最大值（背压例 15.3 s > 总耗时 9 s），
  阻塞仅数字，压缩协商短标签。复核问题：详情上方 10 行标识挤压观测；轨道标签挤；列表细条几乎不可见且比例只在 tooltip；
  账号错误数左右重复；“—”含义不明；WS 阻塞缺失与 0 混淆；旧记录整块消失。
- **R2**：观测块移到统计卡与错误消息之后，标识收入一层“标识与元数据”（字段全保留）；轨道标签“上游/下游”+一行紧凑图例；
  阻塞 null→“–·未测”、实测 0→“0 ms”；旧记录“无观测数据”；列表条加粗加描边，表头常驻“本页 0–X · ▮首输出”；
  账号右侧去重复错误数、正常不再重复说明、原因换行不截断、套餐无窗口“不适用”。
- **最终验收（父级真实浏览器）**：桌面与 375 宽；SSE 背压详情时间轴到 15.3 s；列表表头「本页 0–30 s · 首输出」常驻；
  旧记录显示「无观测数据」；WS 上游 unrecognized 显示「无法识别」、客户端未协商显示「未协商」；暗色快速浏览可读。
  键盘发现缺陷：弹窗内 Tab 到不了新的 `<summary>`（精确值 / 标识与元数据）。原因：共享弹窗焦点陷阱的选择器
  `button,a[href],input,select,textarea,[tabindex]` 不含 `summary`，且 Tab 被 preventDefault 后只在该列表内循环。
  修复：共享块新增 `tabbables(m)`，加入 `summary`，并排除已关闭 details 内的内容、隐藏与禁用控件；先写回归（失败）再修复（通过）。
- **最终键盘回测（父级真实浏览器，修复后新二进制）**：弹窗内从「关闭」Tab 依次到上一条/下一条/「精确值」summary/「标识与元数据」summary；
  Enter 展开、Space 折叠正常；已关闭 details 的子项不抢焦点；Escape 关闭后可再打开。账号页强制刷新后额度/重置/未知/状态布局正常。非全面无障碍审计。
- 回归保护：`scripts/ui-observation-check.cjs`（已接入 CI）及原有 ui/settings/accounts state check。
